# 🎥 Movie Match

**Movie Match** is a content-based movie recommendation web app built with **Python** and **Streamlit**.  
It suggests movies similar to your favorite title using a pre-trained similarity model and displays posters via the **TMDB API**.

🌐 **Live Demo:** [https://movie-recommendation-system-ml-b8e0834da019.herokuapp.com/](https://movie-recommendation-system-ml-b8e0834da019.herokuapp.com/)

---

## 🚀 Features

- 🔍 Search for any movie from the dataset  
- 🎯 Get the top 5 similar movie recommendations  
- 🖼️ View dynamic movie posters fetched from TMDB  
- ⚙️ Fast, lightweight, and interactive UI built with Streamlit  

---

## 🧠 Tech Stack

- **Frontend:** Streamlit  
- **Backend:** Python  
- **Data Handling:** Pandas, Scikit-learn  
- **API Integration:** TMDB API  
- **Deployment:** Heroku
